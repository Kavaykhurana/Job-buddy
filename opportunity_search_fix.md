# Opportunity Search Repair

The Opportunities page now has two synchronized, state-bound search inputs: the original filter-rail field and the prominent search-strip field above results. Both search the same role, organisation, skill, location, status, and opportunity-type index. Delivery mode and eligibility filters use the same state, while Reset clears every active search/filter input.

The desktop and mobile reviews confirmed the search-strip input is visible and accessible. On mobile, supporting result-count/filter chrome is intentionally hidden so the user receives a full-width search field.
